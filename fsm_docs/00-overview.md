# FSM Platform Overview

## Purpose

Field Service Management platform for service companies.

Core capabilities:
- Ticket management
- Dispatching
- Mobile engineer workflow
- Equipment lifecycle tracking
- Warehouse accounting
- SLA monitoring
- Customer communication

## Actors

- Customer
- Operator
- Dispatcher
- Engineer
- Administrator

## Architecture Goals

- SPA frontend
- REST API backend
- PostgreSQL database
- Background jobs
- Real-time updates
- Offline-capable mobile application
