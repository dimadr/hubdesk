# User Stories

## Create Ticket

As a customer
I want to create a ticket
So that service work can begin

## Accept Ticket

As an engineer
I want to accept assigned work
So that SLA response tracking starts

## Complete Ticket

As an engineer
I want to complete a ticket
So that work can be closed

Acceptance:
- checklist complete
- required photos uploaded

## Transfer Inventory

As a dispatcher
I want to transfer materials
So that engineers receive required stock
