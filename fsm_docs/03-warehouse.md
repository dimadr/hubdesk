# Warehouse Module

## Nomenclature Types

- Material
- Product
- Service
- Work

Only Material and Product affect stock balances.

## Warehouse Types

### Physical
Regional warehouse.

### Personal
Engineer stock.

## Documents

### Inflow
External source -> Warehouse

### Transfer
Warehouse A -> Warehouse B

### Write Off
Warehouse -> Consumption

## Workflow

DRAFT
-> APPROVAL
-> DELIVERY
-> ACCOUNTED

Only ACCOUNTED affects balances.
