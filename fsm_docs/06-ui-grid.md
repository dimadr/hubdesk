# Ticket Grid

## Features

- Table View
- Card View
- Sticky Columns
- Column Resize
- Column Reorder
- Tree Grid
- Saved Views
- Tabs
- Real-Time Counters

## Visual Indicators

Overdue:
row highlight

Waiting For Response:
bold subject

Internal Ticket:
lock icon

Priority:
colored left border

## Search

Global search:
- ticket number
- subject

Numeric search should open ticket directly.
